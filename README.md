# Setup

1. navigate to `src/name-of-bookmarklet.js` above
2. at the top, copy the raw file (see image below)
3. create a bookmark literally anywhere
4. edit the bookmark
    - **on desktop:** right click your new bookmark and click `Edit`
    - **on mobile:** go to the `⋮` menu by the address bar, tap `Bookmarks`, then tap the `⋮` menu next to the new bookmark you created and tap `Edit`.
5. paste into the `URL` field, overwriting whatever is there.
6. name it whatever you want

![instructions](./resources/instructions.png)

# Running

### desktop

just click the bookmark you created on your bookmarks bar while on any page.

### mobile

while on a website, tap your address bar and start typing the name you gave the bookmark. among the search and website suggestions will be a "link" to your bookmark. tap that to activate the code on the current page.

navigating to the `Bookmarks` tab in the `⋮` menu will **NOT** work, as the script will have no knowledge of the website you were on.
